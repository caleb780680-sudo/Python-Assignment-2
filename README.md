# 🐍 Python Assignment 2

## 📌 Project Overview

This project contains a collection of Python programming exercises focused on **lists, dictionaries, sets, and conditional statements**.

The assignment provides practical experience with Python data structures, modifying and accessing data, performing set operations, and creating a simple performance-category program based on user input.

---

## 🎯 Objectives

The main objectives of this assignment are to practice:

* Creating and modifying Python lists
* Accessing list elements
* Using list methods
* Performing calculations on list values
* Creating and updating dictionaries
* Accessing dictionary keys and values
* Working with sets
* Understanding duplicate removal in sets
* Performing union and intersection operations
* Using `if`, `elif`, and `else`
* Taking numerical input from the user
* Creating a simple classification program

---

## 📝 Tasks Included

### 🔹 Task 1: List Operations

The assignment creates two lists:

```python
age_list = [24, 25, 27, 28, 29]

name_list = ["Zara", "Ravi", "Priya", "Kumar", "Sita"]
```

Various list operations are performed, including:

* `append()`
* `insert()`
* `remove()`
* `pop()`
* `extend()`
* `sort()`
* `max()`
* `min()`
* `sum()`

The `age_list` is sorted in descending order and the maximum age, minimum age, and total of the ages are calculated.

### 🔹 Task 2: Dictionary Operations

A dictionary named `student_marks` is created to store student names and their marks.

```python
student_marks = {
    "Zara": 85,
    "Ravi": 78,
    "Priya": 92,
    "Kumar": 67,
    "Sita": 88
}
```

Operations performed include:

* Accessing a student's mark
* Adding a new student
* Updating an existing student's mark
* Using `keys()`
* Using `values()`
* Using `items()`

Example:

```python
student_marks["Janani"] = 80
student_marks["Ravi"] = 82
```
